## 版本状态

| 版本                    | 分支（参考）   | 能力                                                                                                                                    |
| ----------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **MVP / v0.1**          | `dev_00_01_00` | Registry + GHA webhook/reconcile + CF Builds + `/dashboard` 关注/归档；CF 成功即归档；合入 master job 回填                              |
| **v0.2（Phase 3）**     | `dev_00_02_00` | 失败/链断裂 → notify-worker；Overview 源过滤；sparkline 按首个 github stage；失败仓优先对账                                             |
| **v0.3**                | `dev_00_03_00` | GitHub Actions 失败日志：Queue 拉取 → R2 zip + D1 摘要；Dashboard 展开/下载；告警邮件附摘要                                             |
| **Release PR registry** | `dev_00_04_00` | 标准轨五段：`ci-check` → `qodana` → `ocr` → `release-merge` → `cf-release`；r2 / lib-newbook / manim 纳入标准轨                         |
| **需求规划**            | `dev_00_05_00` | 需求 PGREQ → 迭代 PGVER → 跨仓上线计划 → 序列图控制台；R2 附件 + 独立脚本桶                                                             |
| **Worker Registry**     | `dev_00_06_00` | CF Scripts 元数据快照、env 指纹、对账告警、`/dashboard/registry`；见 [requirement/worker-registry.md](./requirement/worker-registry.md) |
| **GHA Stats**           | `dev_00_07_00` | Actions step 级耗时 + 额度预警、`/v1/gha/*`、`/dashboard/gha`；上线计划见 [requirement/gha-stats.md](./requirement/gha-stats.md) §8     |

改 registry：编辑 YAML → `npm run sync-registry` → push 部署本 Worker（**本版不做** KV/R2 热加载）。

## Backlog（Phase 4+）

- `/dashboard/insights` KPI
- Registry 热加载
- 成功日 digest
- CF Builds 失败日志
- 历史 failure 补拉日志（cron 扫 `failure_log_fetched_at IS NULL`）
- GHA Stats：邮件 Agent 查询（与 registry 共用）、异常检测、per-repo 预算
