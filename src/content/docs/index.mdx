# workers-world 文档

workers-world 组织下 Cloudflare Workers 生态的内部文档入口。

## 内容范围

- **架构**：Edge Gateway、投资 RSS、分析引擎、流水线跟踪等
- **运维**：发布回退、质量运维、Git remote 切换
- **Worker**：各 Worker 摘要与 GitHub 子仓链接

## 权威副本

本站为**对内发布的精选副本**。开发期权威文档仍在 `cloudflare_work` meta 仓的 [`docs/`](../docs/) 目录；大改请先在 meta 仓完成，再同步至本站。
