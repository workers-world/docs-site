Agent 执行生成的代码（沙箱运行）

涉及隐私的时候就需要沙盒了

因为不想要暴露本机

特别是在给完全访问权限的时候

首先，如果是需要给外部很多用户使用的话，那就肯定需要给每个用户开一个沙盒

这个场景不难理解

具体到个人的话，本机使用的场景比较少，因为agent工具很多都自带了，不需要你去设置
就算是要跳出沙盒也会去申请你的授权。

云上自动化场景我认为用的比较多
因为资源都是临时申请、用后回收的

- get resource
- clone repo
- agent install
- do the business worker
- get the result
- close the resource
